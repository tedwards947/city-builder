Seaport mocks

The seaport is a 4×3 yard on land plus a row of 4 docks over open water, and it turns so the docks can face water on any side. The game's camera never turns, so the port can't simply be rotated as a picture. Its layout turns: the quay, cranes, containers and sheds move to match the water, and each piece is still seen from the same camera as every other building.

Everything below is drawn by code (no paid images), with real clay sprites around it for scale. Each design is shown in all four turns. Mark Yes or No, then Copy feedback and paste it to Claude. You can say yes to more than one in a section.

E. Painted kit trial (one sprite sheet)

One paid image held all the props, so they share one camera, lighting and scale, and each keeps its painted shadow. It came back with seven props: three cranes, an office, two container blocks and a gate booth. Below they're laid out on A1's plan with the B3 stone quay. Code draws the ground, quay and ship.

What worked: the side-on crane (flipped for docks west), the office, the gate and the shadows. What didn't: I asked for cranes with the boom pointing away and pointing towards the camera, and got the same end-on crane twice, with no boom. Here code draws a striped boom on it for docks north and south. The container blocks and the office came back turned slightly, so a second sheet (raw-port/sheet-2.png) redid them square to the camera by swapping each house in the reference image for one prop.
